# FraudSpike AI limitations

## Current scope

- Synthetic demo dataset only
- Local environment, not production production billing infrastructure
- Razorpay integration remains demo/test-oriented unless explicit credentials are configured
- Deterministic evidence-grounded investigation is the default mode
- No live external LLM required for this product flow

## Known trade-offs

The current evaluation shows high recall with a meaningful false-positive cost. This is an honest operational trade-off and not a bug in the reporting.
